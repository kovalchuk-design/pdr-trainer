# ПДР Тренажер (категорія B)

Вебзастосунок для підготовки до теоретичного іспиту з ПДР: навчання, пробні іспити (20 питань, 20 хв, до 2 помилок), робота над помилками, прогрес.
Працює в браузері, його можна додати на головний екран телефона. Прогрес зберігається лише на пристрої.

Питання й правильні відповіді: офіційна база ГСЦ МВС (наказ від 04.09.2025, таблиця відповідей від 29.10.2025 № 225). Пояснення неофіційні.
